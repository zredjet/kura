# 第三者のライセンスの本文の写し

`upstream/` は、crates.io のパッケージにライセンスの本文（著作権表示）が入っていない依存のために、上流のリポジトリの
ファイルをそのまま写したものです。`pnpm run licenses` が `THIRD_PARTY_LICENSES.md` を作るときに使います（ADR-151）。

- ディレクトリの名前は `<リポジトリ>-<コミットの先頭 8 桁>`、その下は上流のリポジトリの中のファイルの名前のままです。
- 出どころ（リポジトリとコミット）・SHA-256・どのクレートのどの版に載せるかは `scripts/third-party-licenses.mjs` の
  `UPSTREAM_FILES` と `UPSTREAM_TEXTS` に書いてあります。
- 手で書き換えないでください（SHA-256 が合わないと生成が止まります）。依存の版を上げたら、その版を公開したコミット
  （パッケージの `.cargo_vcs_info.json`）の上流のファイルを確かめ直してください。
