# デザイン

## 1. 参照するもの

| もの | 場所 | 使い方 |
|---|---|---|
| デザインキャンバス | claude.ai のアーティファクト「Kura メディアライブラリ」（ブラウザで見る） | 見た目の確認 |
| 画面ごとのモック | `docs/design/mockups/*.dc.html` | 正確な余白・色・サイズを読む。インライン style が値の正本。`{{…}}` はテンプレートの差し込み、`<sc-for>` は繰り返し、`<dc-import>` は子部品で、そのままではブラウザで表示できない |
| トークン | `docs/design/tokens.css` | `src/styles/tokens.css` にコピーして使う |

モックとトークンが食い違ったら、トークンを優先します。

## 2. 方針

1. **コンテンツが主役**：地は無彩色の暗色。色はメディアとアクセント 1 色だけに任せる。
2. **ガラスは浮いている部品だけ**：サイドバー、インスペクタ、ミニプレーヤー、再生バー、ダイアログ。macOS 27 の Liquid Glass の方向（読みやすさ優先）に合わせ、不透明度は高め（0.84〜0.94）。
3. **Mac らしさ**：SF Pro とヒラギノ、信号機はサイドバーの中、Mac の標準ショートカット、右クリックメニュー、ドラッグ＆ドロップ。
4. **キーボード第一**：主要操作はすべてキーで届く（§6）。
5. **静かな動き**：120〜180ms の ease-out。視差やバウンドは使わない。

### 3.1 モックにまだない画面（実装時に作る）

- **ユニット単位のプレイリスト**（`docs/playlists.md` §7）
  - タイトル横に「単位」のセグメント（ファイル｜ユニット）。新規作成ダイアログにも同じもの。
  - ユニット行：高さ 60px、44px の表紙（奥に 2 枚、4px ずつずらした板を重ねる）、名前（14px semibold）、「10 ファイル · 画像 · 1:20」（12px tertiary）、▸（展開）、並べ替えハンドル。展開した中身は左を 28px 下げた 44px 行。
  - 単体の行：名前の後ろに小さなラベル「単体」（11px、`--fill-1` の地）。
  - ファイル単位で展開された行の前には、見出し「鎌倉（フォルダ）から · 24 件」（11px tertiary、高さ 28px）。
  - 複数アイテムをユニット単位のプレイリストに落としたときのポップオーバー：「1 つのユニットにまとめて追加」「1 件ずつ追加」の 2 択＋「次回も同じ」チェック。
  - 実装（M6）：手動・スマートとも同じ画面（`src/features/playlists/`）。見出しは Playlist.dc.html の表紙モザイク・種類・名前（押すと名前を変える）・件数と長さ、右に「再生」「続きから（7 / 42）」（保存した位置があり、そのプレイリストを再生していないときだけ）「作り直す」（スマート）「…」。手動の設定は、スマートのルールの下段と同じ並びの面に置く（ADR-81）。
  - 手動の一覧：行を選んで ⌫ で外す、↩・ダブルクリックでそこから再生、ハンドルで並べ替え、右クリックで「ファイルに固定」など。ライブラリのタイル・フォルダはサイドバーのプレイリストの行や一覧に落として追加する（⌥ で展開を逆にする）。ポップオーバーは小さなシート（ADR-87）。
  - スマート：ルールは 1 行 1 条件（種類の選択・演算子・値・−/＋）で、変えると少し待って保存し、並びを作り直す。下に「今回の並び」の表（#・名前・種類・長さ・評価・最終再生）。ダブルクリックでその行から、表示している並びのまま再生する。
  - 「ファイルに固定」のあとは知らせのカプセルに「元に戻す」を出す（ADR-82）。
- **ユニットのタイル**（グリッドで「ユニットをまとめて表示」がオン）：表紙のタイルの奥に 2 枚の板（`--fill-3`、上に 3px と 6px ずらす）、右下に件数バッジ（「10」＋重なりアイコン）。ダブルクリックでユニットの中身を開き、ツールバーの見出しに「すべて › 鎌倉」のパンくず。
  - 実装（M3）：板はタイルの枠の中に収め、表紙を 6px 下げる。切り替えはツールバーの重なりアイコンのボタン（`aria-pressed`）。中身の表示は日付見出しなしでユニットの並び順。「すべて」を押すか ⌘↑ で戻る。
- **ユニットのインスペクタ**：プレビューに表紙、名前、種類（ファイル群／フォルダ群）、件数・合計時間、並び順、ユニット内シャッフル、画像の表示時間、評価、タグ、参照フォルダ（folder のとき）。
  - 実装（M3）：ユニットのタイルを選んだとき、またはユニットの中を開いて何も選んでいないときに出す。下に「中身を開く」（主ボタン）と「ユニットを解除」。folder ユニットはサイドバーのフォルダの右クリック「ユニットとして開く」で中を開く。
- **クイックルック**：黒地全画面、上に名前と「3 / 128」、左右にナビゲーションボタン、esc で閉じる。
- **新規プレイリストのダイアログ**、**ユニット作成のダイアログ**（名前入力だけの小さなシート）。
  - 実装（M3）：小さなシートは幅 420px（`Dialog` の `size="sm"`）。名前の入力・取り消せない操作の確認・候補から選ぶ（フォルダ・ユニット・タグの統合先）の 3 種類を共通の部品にする。
- **右クリックのメニュー**（M3）：ガラスの小さな面（`--glass-dialog`、角丸 12px、行 28px）。右にキーの表記。⌃Return でも開き、↑↓・Return・esc で操作する。インスペクタ下の「その他の操作」も同じメニュー。
- **タグの編集**（M3）：タグのチップの名前を押すと開く小さなシート。名前空間・名前・色（色なし＋フォルダと同じ 4 色）・別名・親タグ、「ほかのタグに統合…」「タグを削除…」。
- **複数選択のインスペクタ**（M3）：最初の 3 件のサムネイルを少し傾けて重ね、「N 項目を選択」。一部にだけ付いているタグは点線のチップに「3/5」を添え、押すと全件に付ける。
- **操作の知らせ**（M3）：画面の下中央に浮かぶガラスのカプセル（4 秒で消える。読み上げもする）。
- **⌘K パレット**（M4）：Search.dc.html のとおり。入力欄は枠を持たず、解析エラーの位置に `--danger-text` の波線、理由は件数の行の右に出す。新しいスマートフォルダ・条件の編集のときも同じパレットで、↵・⌘↵ が保存になる。
- **ツールバーの検索欄**（M4）：押すと ⌘K パレット。条件があれば条件を文字で出し、右に × （条件をクリア）。
- **フィルタバー**（M4）：種類のセグメントと評価・タグ・長さ・取得元のチップ。評価・長さ・取得元はメニューで選び、オンのチップは `--fill-pressed`＋白文字。ほかの条件は Search.dc.html のトークンと同じチップで並べる。
- **ドラッグ中の印**（M3）：ポインタの横に「3 項目」やフォルダ名のカプセル。落とせるフォルダの行はアクセントの枠、並べ替えの位置は 2〜3px のアクセントの線。
- **シアター・ミニプレーヤー**（M5）：Player.dc.html・Main.dc.html のとおり。モックとの違い：
  - シアターの上部は信号機の分だけ左をあける。メディアの面の地は `--bg-media`（代表色は使わない）。右パネルは「キューを表示」でキュー、「情報」「タグを編集」で今のアイテムのインスペクタ（同じ部品）。
  - プロキシの作成中・再生できない・キューの終わりは、メディアの中央にガラスのカード（見出し・説明・ボタン「外部プレイヤーで開く」「もう一度変換する」「はじめから再生」「再生を終える」）。
  - キューのパネルの下のスイッチは「画像の間も直前の音楽を流す」「BGM をループ」。プレイリストの再生中は「同じ種類を3回以上続けない」も出し、変えるとプレイリストの設定を変える（M6、ADR-83）。
  - M6：シャッフル中は上部に「シャッフル（シード 1A2B）」、キューのパネルの右上に「並べ直す」。ユニット単位では「ユニット 3 / 12 · 2 / 10」と出し、キューは今のユニットだけ開いて、ほかはユニットの見出し（名前・件数）に畳む（見出しを押すと開く。単体のアイテムは見出しなし）。
  - ミニプレーヤーの右端に「再生を終える」（×）。取り込みの進捗はミニプレーヤーの上に積む。
- **ダウンロード**（M7）：Downloads.dc.html の左と右下（キャプチャの欄は M8）。
  - URL を入れると少し待って判定し、「YouTube を検出 · yt-dlp」のチップと選択（画質・音声のみは yt-dlp のときだけ。保存先・自動タグ。再生リストのページなら「再生リストをユニットに」）。ツールがなければチップの代わりに警告。↩ か「追加」で積む。選んだ内容は次回の既定。
  - 一覧の行：表紙（取り込んだあとはサムネイル、取得中はダウンロードの印）・題名（わかるまでは URL）・サイト・ツール・状態（取得中は割合）・進捗バー・説明。操作は取得中が一時停止と中止、一時停止中が再開と中止、待機中が「先に取得する」と中止、完了が「ライブラリで表示」、失敗・中止が「ログ」と「再試行」。
  - 右の外部ツール：版と、行の「…」で場所の指定。足りないものがあれば「入れ方」（`brew install …` をシートで、コピーできる）。「更新を確認」も同じシート。下に Cookie の読み込み元（メニュー）と「取得の規則」（小さなシートで名前・正規表現・ツール・追加の引数）。
- **キャプチャ**（M8）：Downloads.dc.html の右上の欄。ルールのカード（名前・撮り方の印・URL パターン・対象または幅・非表示・保存先・最終実行と結果）を押すと編集のシート。「ルールを追加」は点線のボタン、「ログイン用に開く…」は欄の下。ログイン用の Chrome を開いているあいだは「ログイン用の Chrome を開いています（DevTools 接続中）」と「このページを撮る」「ページ全体を撮る」「閉じる」（ADR-111）、「⌃⌥⌘C でも撮れます（ログイン用の Chrome を前面にして押します）」（ADR-112）。「見たままキャプチャ…」で URL を聞いてアプリ内ブラウザを開き、開いているあいだは欄に URL と「このページを撮る」「閉じる」。URL の欄がルールに一致すると「ルール「…」で撮影 · Chrome」と出し、ダウンロードの選択は隠す。サイドバーの「取得 › キャプチャ」は `取得元:capture` で絞り込んだすべての一覧（ADR-106）。
- **表示形式**（M9。ADR-115）：ツールバーの「表示形式」（Main.dc.html：36px のカプセルに 36×28 のボタン 3 つ）。
  - グリッド：正方形のタイル（一辺はサムネイルの大きさの段階の行の高さを目標に、幅いっぱいに広げる。サムネイルは正方形に切り抜く）。日付の見出しはジャスティファイと同じ。
  - リスト：1 行 32px の表（24px のサムネイル・名前・種類・長さ・評価の星・追加日・サイズ）。見出しを押すとその列で並べ替え（同じ列なら向きを変える。種類は並べ替えない）。日付の見出しは出さない。ユニットは名前の後ろに重なりの印と「ユニット · 10」。
  - 選んだ形式は表示の設定として `localStorage`（`kura.view`）に残す。
- **サイドバーを隠す**（⌘⌥S。M9）：隠したときは信号機の分だけツールバーの見出しを右に、プレイリスト・ダウンロードの画面は上をあけ、信号機のまわりをウィンドウのドラッグ領域にする。
- **プレイリストの並べ替え**（M9。ADR-90 の続き）：サイドバーの行をドラッグ（落とす位置にアクセントの線）するか、⌥⌘↑↓。
- **設定画面**：ライブラリの場所、外部ツールのパス、画像の既定表示時間、ユニットをまとめて表示、整合性チェックの結果。
  - 実装（M9。ADR-122）：⌘,（Kura › 設定…）とサイドバーの歯車で開く、アプリ内の広いシート（幅 760px）。上に「一般｜ライブラリ｜ダウンロード」のセグメント、右下に「完了」。
  - 一般：画像の表示時間（選択・その場のキュー用。プレイリストはそれぞれの設定）、ユニットをまとめて表示。
  - ライブラリ：場所（Finder で表示・別のライブラリを開く…・新しいライブラリを作る…）、容量（ライブラリのファイル・ディスクの空き）、整合性チェックの結果と「もう一度確かめる」、DB のバックアップ（一覧・今すぐバックアップ・Finder で表示・戻し方の一文）。
  - ダウンロード：ダウンロード画面の右と同じ外部ツールの欄（ツール・Cookie・取得の規則）と、取得済みの記録（ツールごとの件数と「記録を消す…」。確認のシートを出す）。
  - シートの上にシートを重ねたとき、esc はいちばん上だけを閉じる。
- **サイドバーの下**（M9。Sidebar.dc.html）：区切り線の下に「ライブラリ容量 1.2 TB」と、ディスクの使っている割合のバー（高さ 4px。読み上げは「ディスクの空き …」）、右に設定の歯車。件数が変わったら読み直す。
- **空の状態**：ライブラリが空のとき、中央に「ここにファイルやフォルダをドロップ」と ⌘O の案内。
  - 実装（M9）：一覧の種類ごとに言い分ける（最近の取り込み・未分類・タグなし・フォルダ・スマートフォルダ・ユニット・ゴミ箱）。検索の条件が掛かっていれば「検索の条件に合う項目はありません」と「条件をクリア」。

## 5. 文字と言葉

- 本文 13px、メタ情報 12px、ラベル 11px semibold tertiary。見出しは画面 20px bold、プレイリスト名 30px bold。
- 数字は `font-variant-numeric: tabular-nums`。
- 言葉は短く具体的に：「取り込む」「ユニットにまとめる」「ファイルに固定」「作り直す」。英語の UI 用語は使わない（例外：URL、Cookie、ツール名）。
- 件数は「12,480 項目」、時間は「1:12:40」「8秒」、日付は「今日」「10月8日（木）」。

メニューバー（M9。ADR-116）：ファイル（取り込む ⌘O・新しいフォルダ ⌘⇧N・新しいプレイリスト…）、編集（既定の項目・すべてを選択 ⌘A・タグを追加（T）・フォルダに入れる…（F）・プレイリストに追加…（P））、表示（表示形式 ⌘1〜⌘3 のチェック・サムネイルを大きく ⌘+／小さく ⌘−・ユニットをまとめて表示・サイドバーを隠す ⌘⌥S・インスペクタ ⌘I・フルスクリーン）、項目（再生 ⌘↩・クイックルック（Space）・ユニットにまとめる ⌘G／解除 ⌘⇧G・評価 ▸ ★〜★★★★★（1〜5）・ゴミ箱に入れる ⌘⌫）、移動（検索… ⌘K・ダウンロード ⌘⇧D）、ウインドウ、ヘルプ。修飾キーのないキーは項目の名前に（T）のように添えるだけで、文字の入力を奪わない。

⌘A はメニューの「編集 > すべてを選択」が受ける（ウィンドウが前面にあるとメニューがページより先にキーを取るため。ADR-76）。入力欄にフォーカスがあれば文字のすべてを選ぶ。

## 7. アクセシビリティ

- 文字のコントラストは 4.5:1 以上（`--text-tertiary` まではガラス面の上でも満たす）。
- 色だけで状態を伝えない（失敗は文字「失敗」も出す、除外は点線＋「除外」）。
- タイルは `<button aria-pressed>`、行は `<button>` または `role="option"`（リストボックス内）。
- フォーカスリングは `--focus-ring`。マウス操作時は `:focus-visible` のときだけ出す。
- 「透明度を下げる」がオンなら `data-reduce-transparency="true"` でガラスを不透明にする。設定はウィンドウが前面に戻ったときに読み直す（システム設定で変えて戻ると反映される）。「視差効果を減らす」では動きを止める（`prefers-reduced-motion` で動きのトークンを 0ms にする。JS で動かすアニメーションやスムーズスクロールは使わない）。
- タイル・リストの行の読み上げは「名前、種類、長さ、評価 4」（評価がなければ言わない）。キーで選択を動かしたら、フォーカスも選んだものへ移す（M9。ADR-119）。
