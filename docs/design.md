# デザイン

## 1. 参照するもの

| もの | 場所 | 使い方 |
|---|---|---|
| デザインキャンバス | claude.ai のアーティファクト「Kura メディアライブラリ」（ブラウザで見る） | 見た目の確認 |
| 画面ごとのモック | `docs/design/mockups/*.dc.html` | 正確な余白・色・サイズを読む。インライン style が値の正本。`{{…}}` はテンプレートの差し込み、`<sc-for>` は繰り返し、`<dc-import>` は子部品で、そのままではブラウザで表示できない |
| トークン | `docs/design/tokens.css` | `src/styles/tokens.css` にコピーして使う |

モックとトークンが食い違ったら、トークンを優先します。

## 2. 方針

1. **コンテンツが主役**：地は無彩色の暗色。色はメディアとアクセント 1 色だけに任せる。
2. **ガラスは浮いている部品だけ**：サイドバー、インスペクタ、ミニプレーヤー、再生バー、ダイアログ。macOS 27 の Liquid Glass の方向（読みやすさ優先）に合わせ、不透明度は高め（0.84〜0.94）。
3. **Mac らしさ**：SF Pro とヒラギノ、信号機はサイドバーの中、Mac の標準ショートカット、右クリックメニュー、ドラッグ＆ドロップ。
4. **キーボード第一**：主要操作はすべてキーで届く（§6）。
5. **静かな動き**：120〜180ms の ease-out。視差やバウンドは使わない。

### 3.1 モックにまだない画面（実装時に作る）

- **ユニット単位のプレイリスト**（`docs/playlists.md` §7）
  - タイトル横に「単位」のセグメント（ファイル｜ユニット）。新規作成ダイアログにも同じもの。
  - ユニット行：高さ 60px、44px の表紙（奥に 2 枚、4px ずつずらした板を重ねる）、名前（14px semibold）、「10 ファイル · 画像 · 1:20」（12px tertiary）、▸（展開）、並べ替えハンドル。展開した中身は左を 28px 下げた 44px 行。
  - 単体の行：名前の後ろに小さなラベル「単体」（11px、`--fill-1` の地）。
  - ファイル単位で展開された行の前には、見出し「鎌倉（フォルダ）から · 24 件」（11px tertiary、高さ 28px）。
  - 複数アイテムをユニット単位のプレイリストに落としたときのポップオーバー：「1 つのユニットにまとめて追加」「1 件ずつ追加」の 2 択＋「次回も同じ」チェック。
- **ユニットのタイル**（グリッドで「ユニットをまとめて表示」がオン）：表紙のタイルの奥に 2 枚の板（`--fill-3`、上に 3px と 6px ずらす）、右下に件数バッジ（「10」＋重なりアイコン）。ダブルクリックでユニットの中身を開き、ツールバーの見出しに「すべて › 鎌倉」のパンくず。
  - 実装（M3）：板はタイルの枠の中に収め、表紙を 6px 下げる。切り替えはツールバーの重なりアイコンのボタン（`aria-pressed`）。中身の表示は日付見出しなしでユニットの並び順。「すべて」を押すか ⌘↑ で戻る。
- **ユニットのインスペクタ**：プレビューに表紙、名前、種類（ファイル群／フォルダ群）、件数・合計時間、並び順、ユニット内シャッフル、画像の表示時間、評価、タグ、参照フォルダ（folder のとき）。
  - 実装（M3）：ユニットのタイルを選んだとき、またはユニットの中を開いて何も選んでいないときに出す。下に「中身を開く」（主ボタン）と「ユニットを解除」。folder ユニットはサイドバーのフォルダの右クリック「ユニットとして開く」で中を開く。
- **クイックルック**：黒地全画面、上に名前と「3 / 128」、左右にナビゲーションボタン、esc で閉じる。
- **新規プレイリストのダイアログ**、**ユニット作成のダイアログ**（名前入力だけの小さなシート）。
  - 実装（M3）：小さなシートは幅 420px（`Dialog` の `size="sm"`）。名前の入力・取り消せない操作の確認・候補から選ぶ（フォルダ・ユニット・タグの統合先）の 3 種類を共通の部品にする。
- **右クリックのメニュー**（M3）：ガラスの小さな面（`--glass-dialog`、角丸 12px、行 28px）。右にキーの表記。⌃Return でも開き、↑↓・Return・esc で操作する。インスペクタ下の「その他の操作」も同じメニュー。
- **タグの編集**（M3）：タグのチップの名前を押すと開く小さなシート。名前空間・名前・色（色なし＋フォルダと同じ 4 色）・別名・親タグ、「ほかのタグに統合…」「タグを削除…」。
- **複数選択のインスペクタ**（M3）：最初の 3 件のサムネイルを少し傾けて重ね、「N 項目を選択」。一部にだけ付いているタグは点線のチップに「3/5」を添え、押すと全件に付ける。
- **操作の知らせ**（M3）：画面の下中央に浮かぶガラスのカプセル（4 秒で消える。読み上げもする）。
- **⌘K パレット**（M4）：Search.dc.html のとおり。入力欄は枠を持たず、解析エラーの位置に `--danger-text` の波線、理由は件数の行の右に出す。新しいスマートフォルダ・条件の編集のときも同じパレットで、↵・⌘↵ が保存になる。
- **ツールバーの検索欄**（M4）：押すと ⌘K パレット。条件があれば条件を文字で出し、右に × （条件をクリア）。
- **フィルタバー**（M4）：種類のセグメントと評価・タグ・長さ・取得元のチップ。評価・長さ・取得元はメニューで選び、オンのチップは `--fill-pressed`＋白文字。ほかの条件は Search.dc.html のトークンと同じチップで並べる。
- **ドラッグ中の印**（M3）：ポインタの横に「3 項目」やフォルダ名のカプセル。落とせるフォルダの行はアクセントの枠、並べ替えの位置は 2〜3px のアクセントの線。
- **設定画面**：ライブラリの場所、外部ツールのパス、画像の既定表示時間、ユニットをまとめて表示、整合性チェックの結果。
- **空の状態**：ライブラリが空のとき、中央に「ここにファイルやフォルダをドロップ」と ⌘O の案内。

## 5. 文字と言葉

- 本文 13px、メタ情報 12px、ラベル 11px semibold tertiary。見出しは画面 20px bold、プレイリスト名 30px bold。
- 数字は `font-variant-numeric: tabular-nums`。
- 言葉は短く具体的に：「取り込む」「ユニットにまとめる」「ファイルに固定」「作り直す」。英語の UI 用語は使わない（例外：URL、Cookie、ツール名）。
- 件数は「12,480 項目」、時間は「1:12:40」「8秒」、日付は「今日」「10月8日（木）」。

## 7. アクセシビリティ

- 文字のコントラストは 4.5:1 以上（`--text-tertiary` まではガラス面の上でも満たす）。
- 色だけで状態を伝えない（失敗は文字「失敗」も出す、除外は点線＋「除外」）。
- タイルは `<button aria-pressed>`、行は `<button>` または `role="option"`（リストボックス内）。
- フォーカスリングは `--focus-ring`。マウス操作時は `:focus-visible` のときだけ出す。
- 「透明度を下げる」がオンなら `data-reduce-transparency="true"` でガラスを不透明にする。「視差効果を減らす」では動きを止める。
