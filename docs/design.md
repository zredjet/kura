# デザイン

## 1. 参照するもの

| もの | 場所 | 使い方 |
|---|---|---|
| デザインキャンバス | claude.ai のアーティファクト「Kura メディアライブラリ」（ブラウザで見る） | 見た目の確認 |
| 画面ごとのモック | `docs/design/mockups/*.dc.html` | 正確な余白・色・サイズを読む。インライン style が値の正本。`{{…}}` はテンプレートの差し込み、`<sc-for>` は繰り返し、`<dc-import>` は子部品で、そのままではブラウザで表示できない |
| トークン | `docs/design/tokens.css` | `src/styles/tokens.css` にコピーして使う |

モックとトークンが食い違ったら、トークンを優先します。

## 2. 方針

1. **コンテンツが主役**：地は無彩色の暗色。色はメディアとアクセント 1 色だけに任せる。
2. **ガラスは浮いている部品だけ**：サイドバー、インスペクタ、ミニプレーヤー、再生バー、ダイアログ。macOS 27 の Liquid Glass の方向（読みやすさ優先）に合わせ、不透明度は高め（0.84〜0.94）。
3. **Mac らしさ**：SF Pro とヒラギノ、信号機はサイドバーの中、Mac の標準ショートカット、右クリックメニュー、ドラッグ＆ドロップ。
4. **キーボード第一**：主要操作はすべてキーで届く（§6）。
5. **静かな動き**：120〜180ms の ease-out。視差やバウンドは使わない。

- **素材の表示**（M11。FR-ASSET-01〜05。モックにない部品なので、ここが正本。`pnpm tauri dev` の画面で見て直す）
  - **市松模様**（透過の下地）：解析で透過（二値・半透明）と分かった画像だけに敷く。未解析・不透明なものには敷かない（読み込み中のちらつきと、むだな描画を避ける）。`--checker-a` の地に `--checker-b` のマス、2×2 の一辺が `--checker-size`（1 マスは 8px）。マスは画面に固定で、拡大率で変えない。`<img>` 自身の地に敷くので、タイル（`object-fit: cover`）では透明な画素の下にだけ見える。
    - 敷く所：タイル・インスペクタのプレビュー・クイックルック・シアター。
    - 敷かない所：表示の短い辺が 48px 未満の所（リストの 24px のサムネイル、キュー・プレイリストの 44px の表紙）。フォントと 3D のサムネイル（字の形・描いたモデルの外は地のまま）。
  - **ドット絵**（実効値は「設定 ?? 自動の判定」）：装置の画素で 1 倍以上に広げるときだけ `image-rendering: pixelated`。縮めるときは補間のまま（細い線が消えないように）。
    - インスペクタ・クイックルック・シアターでは、箱に収まる最大の整数倍に置く（装置の画素で数える。DPR 2 なら CSS の 0.5px 刻み）。1 倍に満たなければ縮めて補間する。
    - 設定：インスペクタの素材の欄に「ドット絵として表示」のセグメント「自動｜はい｜いいえ」。自動の下に今の判定を 11px tertiary で（「自動の判定：はい（4 倍）」）。右クリックのメニューにも「ドット絵として表示 ▸ 自動・はい・いいえ」（複数を選んでいても使える。そろっていればその値にチェック、ばらばらならチェックなし）。
  - **アニメのプレビュー**（aseprite・GIF・APNG・アニメの WebP、格子を設定したスプライトシート）：インスペクタ（220px の枠）とクイックルックで回す。シアターでは先頭のコマで止めたまま（M11）。
    - 実装（M11）：インスペクタではプレビューの枠を置き換える（帯ができるまでは今のサムネイル）。クイックルックではステージいっぱいの枠（地はクイックルックの黒のまま）と、その下に同じ操作の行。
    - canvas に描く（隣のコマがにじまない）。ドット絵なら整数倍・最近傍。透過なら市松模様（MediaImage と同じ規則で、同じ関数 `checkerFor` で決める。枠を測ってから敷き、表示の短い辺が 48px 未満には敷かない）。
    - 枠の下に高さ 28px の 1 行：左に再生／一時停止（28px の丸ボタン、アイコンだけで `aria-label`）、「3 / 8」（12px secondary、tabular-nums。ファイルの中のコマの番号／コマの数）、右にタグの選択（aseprite でタグがあるときだけ。`Select`。「すべてのコマ」とタグの名前）。一時停止中は ← → の小さなボタンでコマ送り。
    - コマの長さはファイルのまま（0ms は 100ms）。プレビューではタグの繰り返しの回数とファイルのループの回数を使わず、ずっと回す。ピンポンは端のコマを重ねない（1 2 3 4 3 2 1 2 …）。タグの選択は保存しない。
    - `prefers-reduced-motion` では自動で再生せず、先頭のコマと再生ボタンを出す。
    - 大きすぎて帯を作れないもの（1 辺 8,192px か 16M 画素を超える）は、先頭のコマ（今のサムネイル）のままにし、素材の欄のアニメの行の下に「大きすぎるためアニメを表示できません」（11px tertiary。M11 の実装）。混んでいて帯を作れない（`Busy`）ときは少し待って 2 回までやり直す。
  - **格子のシート**：素材の欄の「格子」の行の［設定…］で開く小さなシート（`size="sm"`、幅 420px）。
    - 上にその場のプレビュー（元の画像に格子の線を 1px の `--accent` で重ねたものと、その格子で回したアニメ）。
    - 下に数の入力（2 列）：セルの幅・高さ、左上のずれ X・Y、間隔 X・Y、使うコマの数（空なら全部）、コマの長さ（ms）。
    - 解析の推定があれば「推定を使う（16 × 16）」の副ボタン（自動では当てない）。M11 では推定（sprite_grid）を素材の欄に出していないので、まだ置かない。
    - 実装（M11）：入力の下に「セル 8 個」（11px tertiary）。セルが 1 つもできない・使うコマの数がセルより多いときは、そこに理由（`--danger-text`、`role="alert"`）を出して「保存」を押せなくする（数え方はエンジンの `cells_on_axis` と同じ）。
    - ボタンは左に「格子を外す」（設定があるとき）、右に「キャンセル」「保存」（主ボタン）。
  - **波形**：インスペクタの音声のプレビューの下に高さ `--h-waveform`（48px）、幅いっぱい。
    - 列ごとの縦の線で、色は `--text-secondary`（チャンネルはまとめて 1 本）。無音の列も 1 単位の線を引く。
    - ループの区間は `--loop-region`（`--accent` の 22%）の矩形と、両端に 1px の `--accent` の線。試聴中の位置は 1.5px の `--accent` の線。
    - クイックルック（音声）とシアターの音声の表示（今の飾りの波形を置き換える）にも、同じ部品を大きく出す。グリッドの音声のタイルは今の飾りの波形のまま（M11）。
    - 実装（M11）：位置の線は、クイックルックでは `<audio>` の位置、シアターではプレーヤーの位置。段のファイルがない（解析の前）とき、インスペクタとクイックルックは何も描かず、シアターは飾りの波形のまま。ループの区間はどこも解析の事実のループ点で、シアターでは概要でループありのもの（`hasLoop`）だけ素材の欄（`item_asset_get`）を読んで出す。
  - **ループの試聴**：波形の下に［ループを試聴］（副ボタン、繰り返しのアイコン。試聴中は［試聴を止める］で `aria-pressed="true"`）と［はじめから］（副ボタン）。キーは L（もう一度で止める）。
    - ループ点のない音声でも出し、全体をループで試聴する（ボタンの名前は同じ）。
    - ［ループを試聴］は継ぎ目の 3 秒前から、［はじめから］は前奏から鳴らして本体を回す。
    - 本体が長すぎる（64MiB を超える）ものは継ぎ目の前後 4 秒を 1 回だけ鳴らし、ボタンの下に「継ぎ目の前後だけを試聴します」（11px tertiary）。
    - 試聴を始めるとプレーヤーを一時停止する。試聴できないもの（レートが 3〜384kHz の外など）はボタンを無効にし、下に理由（11px tertiary）。混んでいて読めなかったときは知らせのカプセルに「混んでいます。もう一度押してください」。
    - 実装（M11）：［試聴を止める］は、どちらのボタン・L で始めた試聴も止める。［はじめから］は試聴中でも前奏から始め直す。選ぶものが変わったとき・クイックルックを開いたときも止める。解析の前（レートが分からない）は「解析が終わると試聴できます」。長さ（フレーム）は DB にないので、/pcm の先頭の 1 フレームの応答（同じ読み取りの長さ・ループ点）で決めてから本体を取る。「継ぎ目の前後だけ」の一文は、鳴らす前は概要の長さからの見積もりで出し、鳴らしたあとは実際の鳴らし方で出す。
  - **素材の欄**（インスペクタの見出しの直後）：`<section>`、見出し「素材」（ラベルの 11px semibold tertiary）、中は今の情報の表と同じ `<dl>` の 2 列（11px tertiary のラベル、secondary の値）。負の数は U+2212（−）で書く（検索の字句解析が `-` に直すので、写して入力できる）。値のないものは「—」。
    - 画像：大きさ「64 × 64（2 のべき乗）」、透過「なし／あり（二値）／半透明あり」、色数「16 色／256 色より多い」（JPEG・HEIC は計らないので「—」）、ドット絵（上のセグメント）、アニメ「8 コマ · 0.8 秒」、格子「16 × 16 · 12 コマ」か「なし」と［設定…］。
    - 音声：形式「48 kHz · 24 ビット · ステレオ」（非可逆の形式ではビットを出さない）、ラウドネス「−14.2 LUFS（LRA 6.1 LU）」（計れなければ理由。「短くて計れません」）、ピーク「−1.0 dBTP」、ループ「0:04.200 – 1:32.000」とその下に 11px tertiary で標本の位置「185,220 – 4,057,200」（なければ「なし」）。その下に波形と試聴のボタン。
    - フォント：書体名、スタイル、字の数「2,340 字」、形式「OpenType（CFF）」「WOFF2」。
    - 3D：頂点「12,480」、三角形「8,320」、大きさ「1.20 × 0.80 × 0.45」、材質「3」。描けない拡張（Draco・meshopt・スキン）があれば「未対応：Draco 圧縮」（`--warning` の印と文字）で、サムネイルは種類のアイコン。
    - 状態：解析を待っている間は「解析しています…」（11px tertiary）。失敗したら「解析できませんでした（理由）」と「もう一度解析する」（文字のボタン）。
  - **フォントの見本**（インスペクタ・クイックルックのプレビュー）：ライブラリのフォントを FontFace で読み、上に「永あAa」を `--text-specimen`（`--text-primary`）、下に「いろはにほへと ABCabc 0123」を `--text-lg`（secondary、1 行で省略）。読めなければサムネイルを出す。
    - 実装（M11）：インスペクタではプレビューの枠を置き換え、クイックルックでは min(720px, 80vw) × min(360px, 60vh) の地のない枠に出す。書体の名前は `kura-specimen-<ハッシュの先頭 16 桁>`（利用者の書体名とぶつからない）で、離れたら `document.fonts` から外す。
  - **フォント・3D のサムネイル**：フォントは字の形だけのアルファの PNG を CSS の `mask-image` に使い、色は `--text-primary`（地はタイルの `--fill-2`。明るい表示・暗い表示のどちらでも効く）。3D は透明の地に描いたものを `--fill-2` の上にそのまま置く。どちらも 24px の行・44px の表紙・ユニットの表紙でも同じ部品（MediaImage）を通す。
    - 実装（M11）：クイックルックでは、フォント・3D のサムネイルを影なしで枠に収める（一辺 720px まで）。フォントは見本（上の「フォントの見本」）を読めたらそれに替え、読めるまで・読めないときはこのサムネイル（それもなければ種類の絵）。
  - **表示の部品（実装。M11）**：サムネイルと元のファイルは `components/MediaImage` だけが出す（`thumbUrl` はそこでだけ呼ぶ）。作り直し中（`stale`）も今の絵を出し、URL に `thumbRev` を付ける。市松模様は表示の大きさが分かってから敷く（タイル・行は枠の大きさを渡し、プレビューは読めた絵の大きさで決める。分からないうちは敷かない。アニメのプレビューの canvas も同じ `src/lib/asset/pixel.ts` の `checkerFor` を通す）。読めない元のファイル（クイックルック・シアター）は大きいサムネイルに、それも読めなければ種類の絵・飾りの波形にする。インスペクタのプレビューは一覧のキャッシュの新しい概要を使い、作り直し・解析が届いたら替わる。
  - **タイルの印（実装。M11）**：アニメの画像は右下に「重なったコマ」の印＋「8 コマ」（格子の画像は帯で使うコマの数。数が分からなければ印だけで、説明は「アニメ」）。ループ点のある音声は右下の長さのバッジの中、長さの前に繰り返しの印（説明と読み上げは「ループあり」）。
  - **右クリックの「ドット絵として表示 ▸」（実装。M11）**：画像を 1 つ以上選んでいるときだけ、ユニットの操作の下（区切り線のあと）に出す。▸ の行は →・Return・クリック・ポインタを載せると右に面を開き（はみ出すなら左）、← と esc で元の行へ戻る。選択肢は「自動・はい・いいえ」で、選んだもののうち画像の設定がそろっていればその値にチェック（`menuitemradio`）。ユニットのタイル・画像でないものは飛ばす。⌘A で選んだときなど、一覧のキャッシュにない（見えていない）ものはそのまま送り（`item_asset_settings_set` が画像だけに付ける）、そのときはチェックを付けない。
    - メニューバーの「項目 › ドット絵として表示 ▸」も同じ選択肢・同じ当て方（評価 ▸ の次）。一覧で選んでいるものに当て、画像を選んでいない・ゴミ箱を開いているときは ▸ ごと無効。チェックは選択・一覧のキャッシュが変わったら 100ms にまとめて合わせ直す。
    - サムネイルがないとき（作れなかった・描けない拡張・M11 の段 2）は種類の絵（`components/KindArt`）：地はそのまま、中央に種類のアイコン（`--text-tertiary`、stroke 1.8、枠の 36%、72px まで。クイックルックは 120px まで）。タイル・ユニットの表紙・インスペクタのプレビュー・クイックルックで同じ。表・キュー・プレイリストの小さいサムネイルは、ほかの種類と同じく行の種類のアイコン。
  - **種類の並び**：種類を並べる所（フィルタバー・⌘K の件数の内訳・取り込みシートの件数・プレイリストの件数・スマートの種類の行）は、どこも「画像・動画・音楽・フォント・3D」の順（Rust の `ITEM_KINDS` の順。`src/ipc/kinds.ts`）。Playlist.dc.html の見出しの「画像 · 音楽 · 動画」の並びから変えた（M11）。0 件の種類は出さない。スマートの種類の行の選択肢は再生できる 3 種だけ（フォント・3D は候補にならない。docs/playlists.md §1.1）。
  - **取り込みシートの件数**：画像・動画・音楽の欄はモックどおり 0 件でも出し、フォント・3D の欄は 1 件以上のときだけ足す（欄は 4〜6 つを等分）。取り込みの結果のカプセルには、中身が違うので取り込まなかったもの（Aseprite でない `.ase`）を「対象外 N」で足す。
  - **効果音の即再生**：設定シートの一般に行「選んだ短い音声をすぐ鳴らす」、説明「10 秒以下の音声を選んだときに鳴らします。再生中・クイックルック中・複数を選んでいるときは鳴らしません。」と右にスイッチ（既定オン）。
    - 実装（M11）：選ぶものが変わったとき（キー・クリック）に鳴らし、前の音は 10ms で下げて止める。音量は再生の設定の音量。解いた音は 32MB まで持つ。
  - **容量**：設定のライブラリの容量に、ライブラリのファイルとは別の行で「サムネイル」「波形」「アニメ」のキャッシュの大きさを出す（ADR-122 を広げる）。
    - 実装（M11）：「ライブラリのファイル」の行の下に 3 行、値は「2.5 MB（1,234 個）」（サムネイルは音楽のジャケットを含む。ゴミ箱の分も数える）。ファイルを数えるので、ライブラリのタブを開いたときに 1 回だけ読む。数えている間は「数えています…」、読めなければ「—」。
  - **フィルタバーの種類**：セグメントを「すべて・画像・動画・音楽・フォント・3D」の 6 区切りにする（アイコンは 13px：フォントは「Aa」の字形、3D は立方体）。検索の語もラベルと同じ「フォント」「3D」。
    - 幅（CoreText で 12px の文字を測った値）：セグメントは 245.8px → 386.3px（+140.5px）。帯の 1 行（左 12px＋セグメント＋評価・タグ・長さ・取得元のチップ 252.8px＋間隔 6px × 5＋大きさのスライダー 154px＋右 4px）は 698.6px → 839.1px。
    - 既定の窓（1440px、サイドバーとインスペクタを出した状態）のグリッドの列は 860px なので、条件のチップがなければ 1 行に収まる（残り 21px）。`pnpm tauri dev`（WebKit、1440×960）で 1 行に収まり、セグメントは約 383px だった（M11 の段 2 で確かめた）。窓の幅が約 1,420px 未満（今は約 1,279px 未満）か条件のチップがあれば、今と同じく 2 行に折り返す（スライダーが 2 行目へ）。区切りを「その他」にまとめることはしない。
  - **未解析の件数**：⌘K パレットの件数の行の右に、解析で決まるフィールド（透過・ループ・ラウドネスなど）を使っているときだけ「未解析 N 件」（12px tertiary）。未解析のものは、除外（`-透過:あり`）にだけ含まれる（docs/search-query.md §4）。
    - 実装（M11）：N は解析が終わると一致が変わりうるものの数（種類などで決まるものは数えない。数え方は search-query.md §4）。0 件なら出さない。入力中の候補の案内（「入力中の候補」）と並べるときは、その左。
    - 検索の結果の一覧が空のとき：空の案内の 2 行目（12px tertiary）を「未解析の N 件は、解析が終わると一致することがあります」にする（N が 0 なら今までどおり「条件を外すと、この一覧のすべてが出ます」）。
  - **ライブラリの更新**：起動のときのマイグレーションが 300ms を超えたら、窓の中央に「ライブラリを更新しています」（13px secondary と進捗バー。割合が分からなければ溝だけ）。失敗したら理由（バックアップの失敗・空き容量・新しい版のスキーマ・当てる失敗）を分かる言葉で出す。
    - 実装（M11）：窓いっぱいの `--bg-window` の層（ガラスにしない。地はウィンドウのドラッグ領域）に、文字と幅 200px の溝（`--fill-track`、高さ 4px。値のある進捗バーにしない）。起動の途中でも、別のライブラリを開くときでも、どの画面の上にも出す。イベント `library://upgrade` の `started` から 300ms で出し、`finished`・`failed` か開く操作が返ったら消す。
    - 失敗：初回の画面（ライブラリがないときのカード）に、見出し（`--danger-text` と警告の印。code ごと：「新しい版の Kura で作られたライブラリです」「ディスクの空き容量が足りません」「バックアップを作れませんでした」「ライブラリを新しい版にできませんでした」、ほかは「ライブラリを開けませんでした」）・説明（Rust の message。何をすればよいかとライブラリは変えていないことまで書いてある。secondary）・場所（tertiary、選べる）を `--fill-1` の地の枠にまとめる（`role="alert"`）。前回のライブラリを開けなかったときは「見つかりません」の一文の代わりにこれを出す。既存のライブラリを開く操作の失敗も同じ形。

## 7. アクセシビリティ

- 文字のコントラストは 4.5:1 以上（`--text-tertiary` まではガラス面の上でも満たす）。
- 色だけで状態を伝えない（失敗は文字「失敗」も出す、除外は点線＋「除外」）。
- タイルは `<button aria-pressed>`、行は `<button>` または `role="option"`（リストボックス内）。
- 入力欄の Enter（確定・送信）と Esc（取り消し・シートを閉じる）は、日本語入力の変換中と、変換を確定するキーでは受けない（`src/lib/ime.ts` の `isImeKey`。ADR-125）。
- フォーカスリングは `--focus-ring`。マウス操作時は `:focus-visible` のときだけ出す。
- 「透明度を下げる」がオンなら `data-reduce-transparency="true"` でガラスを不透明にする。設定はウィンドウが前面に戻ったときに読み直す（システム設定で変えて戻ると反映される）。「視差効果を減らす」では動きを止める（`prefers-reduced-motion` で動きのトークンを 0ms にする。JS で動かすアニメーションやスムーズスクロールは使わない）。素材のアニメのプレビュー（M11）は画面の動きではなく中身の再生なので、コマの長さで描く。ただし「視差効果を減らす」では自動で再生せず、再生ボタンを押したときだけ回す。
- タイル・リストの行の読み上げは「名前、種類、長さ、評価 4」（評価がなければ言わない）。キーで選択を動かしたら、フォーカスも選んだものへ移す（M9。ADR-119）。
