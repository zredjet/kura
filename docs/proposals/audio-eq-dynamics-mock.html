音声エディタの EQ・スペクトル・ダイナミクスの画面案

docs/proposals/audio-eq-dynamics.md の D4（スペクトルの面の置き場）・D9（試聴だけの重ね）と §4 の画面のイメージです。窓は 1440 × 900pt、殻（舞台・右パネル 340px・下のカプセル・上部）は今の音声エディタと同じ形です。音・曲線・数値は見た目のための作り物です。色は tokens.css の変数だけで、新しい色（スペクトル・GR・スペクトログラムの色の表）はこのファイルの冒頭に「トークンの案」として分けてあります。黄色の番号はこの案の注釈で、画面の部品ではありません。見直し（round 1）の指摘を受けて直した版です。

1. スペクトルでイコライザを直す（M17）

  1. 1表示の切り替え（D4）。上部の中央に「波形｜スペクトル｜スペクトログラム」（⌘1・⌘2・⌘3）。イコライザを足したとき・波形を見ていてイコライザを選んだときにスペクトルへ替わる。ADR-177 の改訂。左の名前と情報の行は切り替えの左端までで省略し、「未保存」は名前の横の印にする。
  2. 2細い波形の帯。曲の全体・選択・再生位置を残し、選択はここで行う。切り詰め・フェード・ループの道具（T・F・R）を押すと波形に戻る。止まっているときのアナライザは、この選択の平均。
  3. 3アナライザ（D3）。後（塗り）・前（実線）・最大の保持（点線）を線の形で分ける。再生中は鳴っている位置、止まっていれば選択の平均。左の目盛りがイコライザの dB、右がスペクトルの dBFS。
  4. 4曲線。合成の曲線は柿色。選んだバンドだけ細い曲線と効く帯の塗りを出し、ほかのバンドの曲線はポインタを載せたときだけ。左右の小さな印のドラッグで Q。オフのバンドは点線の点で、合成に入らない。
  5. 5山をつかむ。ポインタの近くのスペクトルの山に印を出し、そこからドラッグするとその周波数にベルができる。ホバーで周波数・音名とセント・スペクトルと曲線の dB。
  6. 6右パネルの引数。位相（最小｜直線）・出力・バンドの表（行はボタン。キーと読み上げの道）・［＋ バンドを足す］・選んだバンドの欄・［ソロで聞く］。値の欄は右パネルだけ。下に固定のラウドネスと出力の形式を残し、引数の欄はその上でスクロールする。
  7. 7試聴だけの重ね（D9）。聞き比べの隣に「音量を合わせて聞く」（大きいほうを下げる）、カプセルの下の段に「一時的に外して聞く」。どちらも音だけに効き、文書に入らず、取り消しの外。
  8. 8キーと色。面にフォーカスがあるとき ←→ で周波数・↑↓ で利得・⇧ で大きく・⌥ で細かく・⌫ でバンドを消す・Q を押している間ソロ。アクセントは合成の曲線と選んだバンドだけで、バンドごとに色を変えない。

2. スペクトログラム（M17）

  1. 1時間×周波数の面。チャンネルごとの段・目盛り・全体図は波形と同じで、ズーム・パン・選択・ループの旗・再生位置もそのまま使える。縦は対数の周波数。
  2. 2色の表はトークンの案 --spectro-0〜4。メディアの表示として扱い、アクセントを含めない無彩色の明るさの段にする（再生位置・ループの柿色と選択の白が埋もれない）。凡例は表示の設定の並びに。
  3. 3表示の設定（どのノードの前・後を見るか、チャンネルを分ける｜和・L・R・M・S、下限の dB）。表示だけの設定で文書に入らない。
  4. 42.8 kHz の細い線はイコライザのバンド 3 で減らした共振（「イコライザの前」に替えると強く見える）。後の候補「時間×周波数の範囲を選んで減らす」はこの面の上に作る（M17 は表示だけ）。

3. ダイナミクス：コンプレッサーと圧縮量の重ね（M18）

  1. 1圧縮量を曲の全体に重ねる。コンプレッサー・リミッターを選んでいるときだけ、各段の上から下へ、波形の後ろに描く（大きな音のピークを隠さない）。見えている範囲で最も深い所に印。あとから描くので、再生しなくても全体が見える。
  2. 2伝達の曲線。しきい値・比・ニーをドラッグで直す。点は再生位置（止まっていればカーソル）の入力のレベル。
  3. 3メーター（入力・出力・圧縮量）。ADR-177 で退けたメーターを入れる改訂。
  4. 4スタイル（D8：クリーン｜パンチ｜オプト）と引数。パンチ（帰還型）では先読みの欄を出さない。サイドチェーンのフィルタは［スペクトルで直す］でスペクトルの面に移って直す。
