# 要件

優先度：**M** = 必須（v1）、**S** = できれば v1、**C** = 後回し可。
各要件の詳細は括弧内のドキュメントを参照。

## 1. 目的と前提

- 個人用のローカルデスクトップアプリ。画像・音楽・動画を 1 つのライブラリで管理し、混ぜて再生する。
- 対象は macOS（Apple Silicon、macOS 26 以降）のみ。将来 Windows に広げる余地は残すが、v1 では考慮しない。
- 想定規模：アイテム 10 万件、ライブラリ容量 2TB まで。

## 2. 機能要件

### 取り込み・保管

| ID | 優先 | 要件 |
|---|---|---|
| FR-IMP-01 | M | Finder からファイル・フォルダをウィンドウにドラッグ＆ドロップして取り込める。⌘O でも選べる |
| FR-IMP-02 | M | 取り込みはライブラリ内へのコピー。同一ボリュームでは APFS クローンで容量を節約する。元ファイルは変更しない |
| FR-IMP-03 | M | 内容のハッシュ（BLAKE3）で重複を判定し、既存と同じものは複製しない（所属の追加だけ行う） |
| FR-IMP-04 | M | 取り込み前に、種類別件数・合計サイズ・重複の見込みを示すシートを出す |
| FR-IMP-05 | M | 取り込みオプション：取り込み先フォルダ、フォルダ構成の再現、フォルダ名をタグに、ファイル情報からタグ、全件に付けるタグ |
| FR-IMP-06 | S | 取り込みオプション：フォルダごとにユニットを作る |
| FR-IMP-07 | M | 取り込みは中断・再開でき、途中で落ちてもライブラリが壊れない |

### 整理

| ID | 優先 | 要件 |
|---|---|---|
| FR-ORG-01 | M | 仮想フォルダの階層を作れる。1 つのアイテムを複数のフォルダに入れられる。フォルダに色を付けられる |
| FR-ORG-02 | M | アイテムをサイドバーのフォルダにドラッグして所属させられる |
| FR-ORG-03 | M | タグ：名前空間（`作者:` など）、別名、親子関係、色。複数選択への一括付け外し |
| FR-ORG-04 | M | 評価（0–5）、タイトル、メモを編集できる |
| FR-ORG-05 | M | ユニット（管理単位）：ファイル群の set、フォルダ群の folder を作成・編集・解除できる（`docs/playlists.md` §2） |
| FR-ORG-06 | S | ダウンロードした複数ファイルの投稿を自動でユニットにする |
| FR-ORG-07 | M | スマートフォルダ（保存した検索） |
| FR-ORG-08 | M | ゴミ箱（元に戻せる）。ゴミ箱を空にすると実ファイルも消える（確認あり） |

### 閲覧・検索

| ID | 優先 | 要件 |
|---|---|---|
| FR-VIEW-01 | M | 表示形式：ジャスティファイ（既定）・グリッド・リスト。サムネイルの大きさを変えられる。日付で見出しを付ける |
| FR-VIEW-02 | M | インスペクタ：プレビュー、評価、タグ、フォルダ、取得元、メモ、情報 |
| FR-VIEW-03 | M | Space でクイックルック（全画面プレビュー、←→ で移動、動画・音楽は再生） |
| FR-VIEW-04 | S | 「ユニットをまとめて表示」：set ユニットを重なったタイル 1 枚で表示 |
| FR-SRCH-01 | M | ⌘K パレットで検索言語による絞り込み（`docs/search-query.md`） |
| FR-SRCH-02 | M | フィルタバー：種類・評価・タグ・長さ・色・取得元 |
| FR-SRCH-03 | S | 色で絞り込み（サムネイルの代表色） |

### プレイリスト・再生

| ID | 優先 | 要件 |
|---|---|---|
| FR-PL-01 | M | 手動プレイリスト。画像・音楽・動画を混ぜられる |
| FR-PL-02 | M | **単位の切り替え**：プレイリストを「ファイル単位」「ユニット単位」で作成でき、後から非破壊で切り替えられる（`docs/playlists.md` §3） |
| FR-PL-03 | M | ユニット単位では、ユニット（ファイル群・フォルダ群）を 1 エントリとして並べ、シャッフルしてもユニット内の順番を保つ |
| FR-PL-04 | M | スマートプレイリスト（条件・上限・並び）。ユニット単位にも対応 |
| FR-PL-05 | M | ランダム再生：シード固定で再現可能、評価による重み付け、同じ種類の連続制限 |
| FR-PL-06 | M | ミニプレーヤー（常駐）とシアター表示 |
| FR-PL-07 | M | 画像の表示時間を、プレイリスト・ユニット・エントリの単位で設定できる |
| FR-PL-08 | M | 画像の間も直前の音楽を流し続けられる |
| FR-PL-09 | S | 前回の続きから再生 |
| FR-PL-10 | S | 「ファイルに固定」：ユニット・フォルダのエントリをその時点のファイルに置き換える |
| FR-PL-11 | M | WKWebView で再生できない形式は再生用プロキシを自動作成する |

### ダウンロード・キャプチャ

| ID | 優先 | 要件 |
|---|---|---|
| FR-DL-01 | M | URL を貼ると取得方法（yt-dlp / gallery-dl）を判定し、キューに積んで取得する |
| FR-DL-02 | M | 進捗・速度・残り時間の表示、一時停止・中止・再試行、ログ表示 |
| FR-DL-03 | M | 取得したファイルを自動で取り込み、メタデータ（投稿者・作者・タグ・タイトル・URL・投稿日）をタグなどに反映する |
| FR-DL-04 | M | 外部ツールの有無と状態を表示し、見つからない場合は導入方法を案内する |
| FR-DL-05 | S | 規則（URL の正規表現 → ツールと追加引数）をユーザーが追加できる |
| FR-CAP-01 | M | サイト別ルール（URL パターン・対象要素・非表示要素・幅・スクロール回数）で Web ページを自動キャプチャ |
| FR-CAP-02 | S | アプリ内ブラウザで開いたページを「見たまま」キャプチャ |
| FR-CAP-03 | S | キャプチャ用ブラウザでログインしておける |

### その他

| ID | 優先 | 要件 |
|---|---|---|
| FR-SYS-01 | M | 初回起動でライブラリの場所を選ぶ。ライブラリを開き直せる |
| FR-SYS-02 | S | 書き出し：選択したアイテムを元のファイル名で書き出し、タグなどを JSON で添える |
| FR-SYS-03 | S | DB のバックアップ（SQLite の backup API）を定期的に作る |
| FR-SYS-04 | C | 複数ライブラリの切り替え |

## 3. 非機能要件

| ID | 要件（Apple M1 相当、SSD、リリースビルド） |
|---|---|
| NFR-01 | 10 万件のライブラリで、起動から操作可能まで 1.5 秒以内 |
| NFR-02 | 10 万件のグリッドを 60fps でスクロール（サムネイル生成済み） |
| NFR-03 | タグ 3 つの AND 検索が 50ms 以内、全文検索が 100ms 以内 |
| NFR-04 | 画像サムネイル生成が 50 枚/秒以上 |
| NFR-05 | 取り込みはディスク速度が上限になること（ハッシュ計算がボトルネックにならない） |
| NFR-06 | プレイリストのキュー生成が 1 万エントリで 50ms 以内 |
| NFR-07 | メモリ使用量が 10 万件表示中で 500MB 以内 |
| NFR-08 | 強制終了・電源断のあとでも DB とファイルが整合した状態に戻せる |
| NFR-09 | キーボードだけで主要操作ができる。VoiceOver で主要な要素が読み上げられる |
| NFR-10 | 外部への通信はダウンロード・キャプチャ・ツール更新のときだけ |

## 4. 対象外（v1）

- Windows / Linux 版、モバイル版
- クラウド同期、複数ユーザー
- 画像・動画の編集
- 顔認識、AI による自動タグ付け
- App Store での配布
- ストリーミング配信（他の端末への再生）
- 操作の取り消し（⌘Z）の履歴。個々の操作の「元に戻す」の知らせはある（ADR-117）
- 色での絞り込み（FR-SRCH-03 の色。ADR-117）
